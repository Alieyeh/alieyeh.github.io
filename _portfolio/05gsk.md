## Overview

This project used large-scale human genetics data to support early-stage drug discovery and target prioritisation. It was completed during an industry-linked MSc placement with GSK Human Genetics.

## My Contribution

- Performed region-based association analyses using UK Biobank whole-genome sequencing data.
- Developed Python workflows for annotation and processing of rare non-coding genomic regions.
- Integrated analysis steps with HPC-based statistical genetics workflows.
- Supported quality control, interpretation and communication of statistical genetics outputs.

## Technical Scope

- Whole-genome sequencing data
- Rare variant annotation
- Region-based association testing
- REGENIE and HPC execution
- Python and Bash workflow development

## What It Demonstrates

The project strengthened my experience in translational statistical genetics, WGS analysis, reproducible HPC workflows and working within a regulated pharmaceutical research environment.
