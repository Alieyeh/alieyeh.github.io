## Overview

Large research platforms often hold valuable omics datasets, but the surrounding information can be scattered across spreadsheets, project records, free text, file headers and informal documentation. That makes it hard for researchers to know what exists, whether it is suitable for a question, and what approvals or constraints apply.

This project develops a harmonised metadata approach for genomics and multi-omics datasets inside a Trusted Research Environment.

The same thinking is reflected in my published Real World Data Science guide on genomic dataset selection, which sets out a five-pillar framework for evaluating discovery, governance, assay choice, cohort context and quality-control readiness.

## My Contribution

- Designed the initial metadata framework and discovery-tool concept.
- Defined structured metadata fields for dataset type, file structure, cohort context, assay type and access-relevant information.
- Developed the architecture for metadata curation, search and feasibility assessment.
- Supervised intern work contributing to metadata discovery infrastructure.
- Explored NLP-based approaches for extracting useful structure from unstructured dataset documentation.

## Technical Direction

- Cross-modality metadata schema for genomics and related omics data
- Structured representation of common file types and derived outputs
- Searchable index for dataset discovery and comparison
- Governance-aware filtering to avoid surfacing sensitive or disclosive information
- Researcher-facing discovery workflows before formal access applications

## Status

In development. The design supports scalable data discovery while preserving the governance expectations of a secure research environment.
